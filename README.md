# 2.IMCS-IR: 基于BERT+BiLSTM+MLP+CRF的医患对话意图识别模型

本项目针对IMCS数据集中的意图识别任务（IMCS-IR），实现了一个基于BERT+BiLSTM+MLP+CRF的端到端模型。

## 数据集

使用的是智能对话诊疗数据集IMCS，包含医患对话的文本数据，并标注了16种对话意图。
## 模型架构

本项目基于BERT+BiLSTM+MLP+CRF的框架实现：

1. 首先使用BERT提取单条对话语句的句子级语义特征（话语级）；
2. 然后使用BiLSTM对每条句子提取对话中的上下文语义特征（对话级）；  
3. 最后通过双头MLP+CRF进行解码（分别对拆分后的意图和行为进行单独解码）。

## 优化与创新

### 1. 标签拆分
将原有的16种意图标签拆分为2个维度：意图（4类）和行为（9类），转化为2个子任务。这样做的好处有：
- 减少了每个子任务的类别数量，降低学习难度；
- 学习标签之间的关联，挖掘内在联系；
- 细粒度有利于缓解流水线式多任务学习之间的误差传递。

### 2. 对话角色建模
通过数据分析发现，对话意图与说话人角色密切相关。因此在输入中对角色信息进行了显式和隐式的建模。

### 3. 句子位置编码
对话中每个句子的相对位置蕴含着重要信息，本项目通过位置编码将其引入模型。

### 4. 对抗学习
在训练过程中引入对抗学习，具体做法是：在utterance encoder（BERT）的输出上叠加扰动，重新计算后续输出，并在两个输出间计算KL divergence作为loss，提高模型鲁棒性。

### 5. R-Drop
实现了R-Drop策略，同时前向计算两次，得到两组输出logits，计算它们之间的KL divergence作为一致性loss，促进模型的鲁棒性。

### 6. 数据增强
实现了多种数据增强策略，包括：
- 随机交换相邻句子
- 随机插入无意义句子
- 随机MASK token

### 2.模型集成
额外训练macbert、medbert等，集成策略为：

- 对双头解码器进行分别集成，对集成结果再进行组合（集成A，集成B，组合为A-B的形式）
- 采用加权投票，权重为每个子类在验证集中的acc值。

## 运行方式

1. 下载预训练模型（如RoBERTa），放在`plms`目录下
2. 训练：`python trainer.py --output_model_dir ./save_model/存放正在训练模型`
3. 预测：`python predict.py --model_dir ./save_model/训练后的模型 --test_output_file 提交结果名称.json`
